# OpenHandAid · FSHD 等手部肌肉萎缩辅具（开源 3D 打印手展辅助手套）

> 「罕见·无界」黑客松 · 赛题8 · FSHD 等手部肌肉萎缩 + 手部力量辅具
> 依据《FSHD 手部肌肉萎缩辅具 产品需求书 V1.0》（2026-10-01）编写 · 项目代号 **OpenHandAid** · 发起方：Khub 罕见病开源社区 · [OpenRD](https://github.com/OpenRDHub)

面向 FSHD（面肩肱型肌营养不良）、CMT（腓骨肌萎缩症）、MG（重症肌无力）、ALS 等手部肌肉萎缩病友的**开源 3D 打印手部力量辅具**：通过 3D 打印结构、魔术贴固定和弹力辅助，帮助手指从蜷缩状态中打开，支持拿杯、拿碗、拿筷子、打字等轻量日常动作——**让双手在生活中多一点可控感**。

> 定位说明：它不能让萎缩的肌肉恢复功能，而是降低完成日常动作的难度。**仍在迭代中，不是医疗器械，不替代医生、康复师或专业治疗建议。**

## 🧭 一、项目背景

对很多手部肌肉萎缩类罕见病病友来说，手部功能受限不只是"力气小一点"——吃饭、穿衣、拿水杯、回一条微信，都可能需要反复尝试甚至失败。FSHD 典型病程中手指会逐渐蜷缩无法张开。现有辅具普遍存在：价格高、购买与适配渠道复杂、尺寸手型病情差异大难以统一适配、不适合居家长期使用。

## 📐 二、设计理念与三轮迭代

**结构方案**：3D 打印模块化骨架 + 可调节弹力组件——提供**温和、可控的辅助推力**（不是强行掰开），弹力随使用者发力节奏动态变化；外观刻意回避"医疗器械感"，更像一件日常工具。

| 版本 | 重点 | 成果 | 暴露问题 |
|---|---|---|---|
| v1.0 | 验证方向可行性（柔性 TPU + 劳保手套改装） | 能辅助手指伸直与简单抓握，证明"弹性辅助而非强制矫正"可行 | 压迫感、夏季闷热、固定性一般 |
| v2.0 | 转向真实生活长期使用（透气 TPU + PETG 硬质指套、关节联动、可调节拉力、绑带固定） | 伸展效果与发力稳定性显著提升 | 局部夹肉、指套摩擦不足 |
| v3.0 | 以真实佩戴体验为核心重构（镂空网格结构 + 快拆卡扣系统） | 舒适度、透气性、日常可用性明显改善，从"功能可用"走向"愿意长期佩戴" | — |

**参数化设计**：尺寸调整简化为**单一参数修改**，患者无需复杂建模即可在打印现场完成个性化适配。

**真实测评**：来自 FSHD、CMT、MG **三个病种**的病友实测；反馈约 45 分钟佩戴后可能出现勒痕或疼痛（因人而异），部分用户穿脱仍需家人协助——这是当前迭代重点。

## 🛠 三、当前版本能力与技术规格

**能做什么**：手指伸展辅助、手掌支撑、轻量抓握/夹取、场景辅助（拿杯/拿碗/拿筷子/打字）。实测手指展开角度 60°–80°，整重 ≤25g，指腹防滑硅胶垫，关节圆角处理；当前聚焦成人款。

**模型文件**（详见 [MakerWorld 模型页](https://makerworld.com.cn/zh/models/2005480-kai-yuan-shou-zhan-fu-zhu-shou-tao)）：

| 文件 | 说明 | 材料 |
|---|---|---|
| `models/stl/finger.stl` | 指部零件 | PETG |
| `models/stl/hand-heated-part.stl` | 手背/掌部柔性固定结构 | TPU95A |
| `models/stl/strap-holder-v2.stl` / `-thumb-v2.stl` | 魔术贴/绑带固定件 | PETG |
| `models/bambu-studio/openhandaid-public-v1.3mf` | 切片配置件 | — |

**打印参数**：层高 0.2mm / 墙数 2 / 填充 15% / 约 2.3 小时。**BOM**：M3x5 内六角螺丝、勾毛同体魔术贴（2cm/0.5cm）、橡胶圈（弹力辅助）、3D 打印件一套——完整清单见产品需求书。

**继续优化的五个方向**：① 佩戴更简单（独立穿脱）② 更舒适（压痛/勒痕/滑动）③ 更好适配（手掌宽度、指长测量规则）④ 更易复现（打印参数、BOM、组装文档）⑤ 更多动作与手型测试。

## ⚕️ 四、使用与安全边界

**可能适合尝试**：手指自然张开困难、抓握稳定性不足、轻量夹取受限、有明确动作目标并愿意反馈。

**暂不建议自行尝试**：皮肤破损、明显疼痛/麻木/持续勒痕、严重痉挛、关节畸形固定、近期手部手术、医嘱不建议佩戴外部辅具。

**注意**：首次佩戴建议有人协助；不要长时间连续佩戴；出现疼痛/麻木/勒痕立即停用；不要把单次有效体验理解为普遍疗效；不同病种、手型、肌张力差异很大。

## 💰 五、开源与定价原则

- **开源清单**：完整 STL/3MF 模型、参数化说明、使用说明与适用范围（含安全边界）
- **许可证**：**CC BY-NC（署名-非商业性使用）**——可在署名且非商业用途下分享和改编，请勿用于商业用途
- **定价**：不采用市场定价，以**实际成本（材料/打印/运输）+ 合理劳务补贴**为基础，前期以小批量（如 10 套）真实成本核算——病友可负担、参与者不被消耗
- **可持续运营**：优先由罕见病患者家庭成员或居家照顾者参与对接打印、组装与反馈整理

## 🤝 六、如何参与

**病友/家属**：反馈真实使用场景（请匿名，不公开姓名/手机号/病历截图）；有 3D 打印条件可直接下载制作。**3D 打印志愿者**：复现并记录参数。**开发者/研究者**：结构、材料、人机工程、康复工程方向优化。**公益组织/企业**：材料、打印、物流、测试支持。

你可以从很小的事开始：复现一次打印并记录参数、拍一张组装图、改进 BOM 文档、提交一个真实使用问题——一次失败的打印记录也可能帮下一位少走弯路。
